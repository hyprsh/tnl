# Declared Outposts connect with a durable Outpost credential

An Edge can declare its Outposts in its settings, one `TNL_OUTPOST_<LABEL>=<name> <public-key>` per Outpost, and each declared Outpost connects with an Outpost credential instead of joining. The credential is one `tnlc1.` string holding the Outpost's name, WireGuard private key and Tunnel address, plus the Edge's address, port and public key. The operator mints the Edge's line and the credential together, offline, with `tnl credential`, from the Edge's private key. The Edge then takes that key from `--key-file` or `TNL_KEY`, so its public key is known before it first starts, and refuses to start if `state.json` holds a different one. A declared Outpost's Tunnel address is derived from its name, so the Outpost knows it before its first packet, and it stays put when the key rotates or the lines are reordered. This is the long-lived credential that [ADR 0003](0003-outposts-join-inside-the-tunnel.md) rejected, chosen here so that one Compose file on the Edge and one on each Outpost hold the whole setup, as with cloudflared: no `docker exec` round trip, and no state volume on the Outpost. Two things from ADR 0003 hold: the Edge is pinned by its key from the first packet, and the Edge holds only public keys. We chose the Outpost's own WireGuard key as the credential over a reusable join secret that would run ADR 0003's join on every fresh container, because the secret would carry the same power and every recreate would swap the peer's key. Edges that don't declare Outposts keep one-time join tokens. The costs: the Outpost's private key passes through the operator's hands, and anyone holding a credential connects as that Outpost until its line changes. The Edge's address, port and key are baked into every credential, so changing them means minting every credential again, and the Edge's private key must exist outside the Edge to mint them. Two running copies of one credential fight over the peer's endpoint. The credential's format and the name-to-address hash are frozen once Compose files depend on them.

See [Declaring the Edge's Zones and Outposts in its settings](https://github.com/hyprsh/tnl/issues/28).
